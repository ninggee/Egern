# Converted modules

`tools/module_sources.json` is the editable source list. It contains only reviewed public HTTPS module URLs. Add an entry with a unique lowercase `id`, its public `.sgmodule`, `.module`, or `.conf` URL, and the original filename as `name`; remove an entry to stop syncing and prune its generated file on the next run. New hosts also need review and inclusion in the converter's host allowlist. The workflow runs daily at 06:23 Asia/Shanghai, after changes to the source list, or manually from GitHub Actions.

The workflow publishes a source only when the pinned Egern-hub converter reports no unresolved warnings, requires no remote echo or script inspection, and produces parseable YAML without credential-like URLs. Standard redirects and empty JSON responses are normalized to Egern's documented `url_rewrites` format. Surge's `REJECT-NO-DROP` becomes Egern's `REJECT`; other unsupported rule policies and custom responses are not published automatically. A failed or newly unsupported source keeps its last published file and appears in the run summary by ID. Some source URLs were extracted from Script Hub wrappers; the workflow fetches their public upstream directly instead of contacting the local Script Hub endpoint.

The converter is fetched from its pinned upstream commit and verified by SHA-256; its source is not copied into this repository. Argument defaults remain in `compat_arguments`. Parameter-specific descriptions or a single overall description are preserved in `compat_arguments_desc`. The generated modules are syntax-checked, but referenced JavaScript still needs to be compatible with the Egern script runtime.

The workflow manages all `.yaml` files under `modules/converted/`. It replaces the final source extension with `.yaml` while keeping the original capitalization, Unicode, and suffixes such as `.beta`. For example, `Coolapk_Redirect.sgmodule` publishes as `Coolapk_Redirect.yaml`. If names collide (including case or Unicode-equivalent names) or a name is not portable, set an explicit, unique `.yaml` `filename` on that source. IDs are used only for internal artifacts and run summaries. Keep a source's output name stable to preserve its download URL and retain its last published file if a sync fails.

Point the matching module entry in your local Egern profile to the generated file's **Raw** URL, for example `https://raw.githubusercontent.com/ninggee/Egern/main/modules/converted/Coolapk_Redirect.yaml`. Use URL-encoded filenames for non-ASCII characters and spaces. Keep the profile itself, including subscription links, outside this repository.
